# Реферальная система — ТЗ

## Архитектура
- **Отдельный модуль** в `shared/referral/` — общая логика для всех ботов
- **Marketer Bot** уже есть — добавить реферальные хендлеры туда
- **Все боты** (seller, main, mirror) — подключают реферальный middleware (трекинг перехода по ссылке)

## БД (новые таблицы в newlookup.db)
- `referrals` — referrer_id, referred_id, source_bot, created_at, status (pending/confirmed/paid)
- `referral_rewards` — user_id, amount, status (pending_moderation/approved/rejected/paid), reviewed_by, reviewed_at
- `referral_settings` — reward_amount, reward_type (fixed/percent), min_purchase, max_daily_referrals, cooldown_hours

## Логика
1. Юзер получает уникальную ссылку `t.me/bot?start=ref_<user_id>`
2. Реферал переходит → регистрация → привязка к рефереру
3. Реферал делает первую покупку → реферал подтверждён
4. Бонус начисляется в `referral_rewards` со статусом `pending_moderation`
5. Админ в Web Panel → модерация → approve/reject
6. После approve — бонус зачисляется на баланс юзера

## Многоуровневая реферальная система
### Отображаемые проценты (показываем юзерам)
- **Уровень 1 (прямой реферал):** 15%
- **Уровень 2:** 7%
- **Уровень 3:** 3%
- **Уровень 4:** 1%
- **Уровень 5+:** 0.5%

### Реальные выплаты (внутренняя логика, -60%)
- **Уровень 1:** 7%
- **Уровень 2:** 3%
- **Уровень 3:** 1%
- **Уровень 4:** 0.2%
- **Уровень 5+:** не выплачивается
- Коэффициент занижения (`payout_ratio`) хранится в `referral_settings`, настраивается админом
- Проценты настраиваются в `referral_settings`
- Каждый уровень — отдельная запись в `referral_rewards` с указанием level

## Антифрод
- Лимит рефералов в день на юзера (настраивается)
- Бонус только после первой покупки (не за регистрацию)
- Проверка: один Telegram ID = один реферал
- Кулдаун между рефералами
- Модерация выводов — ручная проверка админом
- Антисамореф: нельзя быть рефералом самого себя или кольцевая цепочка

## UI
### Marketer Bot → раздел "Рефералы" (ОСНОВНОЙ ИНТЕРФЕЙС)
- `/referral` — получить уникальную ссылку + inline-кнопка "Скопировать"
- `/referral_stats` — статистика: приглашено / подтверждено / заработано / на модерации
- `/referral_history` — история начислений с датами и статусами
- `/referral_withdraw` — запрос вывода бонуса → уходит на модерацию
- Уведомления (push в бот):
  - "Новый реферал зарегистрировался!"
  - "Реферал сделал первую покупку — бонус $X на модерации"
  - "Вывод $X одобрен / отклонён"
- Inline-кнопки для шаринга ссылки (поделиться в чат)

### Admin Panel → новый раздел "Рефералы"
- Таблица реферальных связей
- Модерация выводов (approve/reject с комментарием)
- Настройки (суммы, лимиты, кулдаун)
- Статистика по системе (топ рефереры, конверсия)

## Интеграция
- Marketer Bot: полный UI рефералов (ссылки, статистика, уведомления, вывод)
- Все боты (seller, main, mirror): middleware на `/start ref_XXX` — трекинг перехода, привязка реферала
- Web Panel: роуты модерации + админ-панель рефералов
- Уведомления через Marketer Bot (notify endpoint)
