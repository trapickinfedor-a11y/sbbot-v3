## 🚀 Быстрый старт

### Локальная разработка

```bash
cd lookup_api
./start_lookup_api.sh
```

### Docker Production

```bash
# 1. Настроить .env
LOOKUP_API_BASE_URL=http://lookup_api:8082
LOOKUP_ADMIN_TOKEN=$(python3 -c "import secrets; print(secrets.token_hex(32))")

# 2. Запустить
docker compose up lookup_api -d

# 3. Создать ключ
docker exec newlookup_lookup_api python3 manage_keys.py create bot_user password --balance 10000

# 4. Сохранить ключ в БД ботов
psql -U newlookup -d newlookup -c "INSERT INTO api_keys (key_name, key_value, key_type, is_active) VALUES ('lookup_api', 'your_api_key', 'lookup', true);"
```

## 🔄 Следующие шаги

### Для production использования:

1. **Импортировать реальные данные:**
   - Получить CSV файлы с SSN/DL/CR данными
   - Импортировать через `importer.py`
   - Перестроить FTS индекс

2. **Создать production API ключ:**
   - Сгенерировать надёжный пароль
   - Создать ключ с достаточным балансом
   - Сохранить в таблице `api_keys` основной БД

3. **Настроить мониторинг:**
   - Настроить алерты на низкий баланс
   - Мониторить размер базы данных
   - Отслеживать производительность запросов

4. **Настроить резервное копирование:**
   - Ежедневный backup lookup.db
   - Хранение в безопасном месте
   - Тестирование восстановления

5. **Оптимизация:**
   - Периодический VACUUM и ANALYZE
   - Мониторинг размера WAL файлов
   - Настройка cache_size при необходимости
