Что ещё добавить в первую очередь

1. Доделать роли

На `admin-roles` нужен полноценный UI для create, edit, delete и назначения прав без ручной работы через API.

2. Починить hidden-модули

Минимум `seller-moderation` и `checks` надо либо вернуть в рабочий поток, либо официально убрать из поддержки.

3. Убрать legacy-дубли

Сейчас несколько экранов дублируют друг друга. Это путает и пользователей, и дальнейшую разработку.

4. Свести права

Матрица доступа в меню и реальный backend-access должны совпадать, особенно для `audit` и системных экранов.

5. Унифицировать layout

Часть старых страниц всё ещё живёт на собственных header/nav, а не на `_base.html`, из-за чего сложнее поддержка.

6. Добавить статус-маркеры в навигацию

Если хочешь, следующим шагом можно прямо в меню показать маленькие метки `beta`, `legacy`, `hidden` для проблемных модулей.
