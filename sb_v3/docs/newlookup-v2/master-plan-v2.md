## 2. Mirror Bot — типы заказов

### Виды товаров/заказов:
1. **Order** — выполняется в реальном времени
2. **Order + Catalog** — воркер загружает позиции ИЛИ выполняет если нет/не хватило
3. **Catalog** — саппорт/админ загружает полный ассортимент
4. **Seller upload** — селлеры загружают через Mini App → модератор одобряет в Support Bot

### UX/UI требования:
- В заказах (Order и Order+Catalog) показывать **ETA** (время ожидания, вводится админом)
- Категории на нужном языке, описания — на выбранном языке юзера
- **В админке: ссылки для всех услуг** — быстрая смена ссылок для Order и Order+Catalog
- Только для Order и Order+Catalog показывать ссылки

## 4. Mini App + Seller Bot — полная переработка

### Seller Bot — новый флоу:
1. `/start` → выбор языка
2. Инструкция/описание на выбранном языке
3. Оплата страхового депозита + описание + предупреждения о бане
4. Ежедневный отчёт по товарам
5. Добавление других селлеров из бота
6. Уведомления: новые сообщения, товар на модерации, покупка, жалоба
7. Докупка доступов к позициям (по одной или полностью) — продумать оплату в Mini App и боте

### Mini App — переработка разделов:

#### Chats
- Подписывать # заказа и позицию к каждому чату
- Механизм отправки спора на модерацию (для селлера и покупателя)

#### Orders
- Это склад одобренных товаров + история

#### Upload — разделить на два:
1. **Upload** — меню загрузки (переработать)
2. **Moderation Status** — отдельное меню отслеживания статусов модерации для ВСЕХ разделов

#### Upload → Banks (Selfreg BA)
- Оставить только "Banks"
- "+ Add custom bank" → запрос через модерацию
- Полное описание на нужном языке на логотипе
- PRODUCT TYPE — возможность добавлять новые названия
- Отдельный тумблер "Есть документы?"

#### Upload → Brute Bank
- "+ Add custom bank" → через модерацию
- Валидация категорий и атрибутов под существующие банки

#### Upload → NFC

#### Upload → Enrollment

#### Upload → Logs

- **Конфигуратор счетов** вверху — предложить варианты пользователю

#### Общее для Upload:

## 6. Admin Panel — детальные правки (от пользователя)

### Юзеры → Рассылки
- Массовые рассылки по будильнику (scheduler) на 4 языках: **EN, RU, ES (испанский), ZH (китайский)**
- Отдельные конфигурационные меню рассылок для: Marketer Bot, Worker Bot, Seller Bot
- Рассылки юзерам с inline-кнопками на все категории (удобный выбор)

### Команда (Team)
- Полная переработка меню для удобства

### Заказы (Orders)
- Разделить по видам (Order / Order+Catalog / Catalog / Seller upload)
- Разные окна модерации для каждого вида

### Каталог (Catalog)
- Полная реорганизация — сейчас беспорядок

### Настройки + Система
- Проработать role-based доступ: что видит owner / moderator / accountant / manager
- Настройки под каждый тип пользователя

## 7. Всё связано: Mirror Bot ↔ Admin ↔ Mini App ↔ Seller Bot
- Все изменения Mirror Bot отражаются в Admin (типы заказов, ETA, ссылки)
- Mini App Upload привязан к модерации в Admin
- Seller Bot онбординг → отображение в Admin → Team
- Рассылки Admin → уходят через Marketer/Worker/Seller ботов
