## 1. Философия привлечения: AIDA-воронка в Telegram

Наша цель — провести пользователя по классической воронке AIDA (Attention, Interest, Desire, Action) полностью внутри экосистемы Telegram, минимизируя переходы на внешние сайты.

| Этап | Задача | Инструмент |
| :--- | :--- | :--- |
| **Attention (Внимание)** | Привлечь внимание целевой аудитории. | Короткие видео (Reels, Shorts), посты в Telegram-каналах, статьи на внешних ресурсах. |
| **Interest (Интерес)** | Вызвать интерес к продукту, показать его возможности. | Посадочный Telegram-канал с кейсами, обзорами, инструкциями. |
| **Desire (Желание)** | Создать желание воспользоваться продуктом, продемонстрировать ценность. | Демо-доступ, отзывы, сравнение с конкурентами, специальные предложения. |
| **Action (Действие)** | Побудить к первому действию — запуску Mirror Bot. | Прямая ссылка на бот с UTM-меткой. |

## 2. Каналы привлечения: от простых к сложным

### Уровень 1: Быстрый старт (0-1 месяц)

**Задача:** Получить первых пользователей и обратную связь.

| Канал | Описание | Бюджет |
| :--- | :--- | :--- |
| **Покупка рекламы в Telegram-каналах** | Найти 10-15 каналов по темам OSINT, информационной безопасности, арбитража трафика. Закупить посты с прямой ссылкой на Mirror Bot. | $500 - $2,000 |
| **Ручное размещение на форумах** | Зарегистрироваться на 5-7 профильных форумах (например, Zelenka, Lolzteam, Exploit) и создавать темы с описанием сервиса, отвечать на вопросы. | $0 |
| **Партнёрство с блогерами** | Найти 3-5 небольших YouTube-блогеров или авторов Telegram-каналов и предложить им партнёрство за процент от привлечённых пользователей. | % от дохода |

### Уровень 2: Масштабирование (1-6 месяцев)

**Задача:** Построить стабильный поток органического и платного трафика.

| Канал | Описание | Бюджет |
| :--- | :--- | :--- |
| **Создание собственного YouTube-канала** | **Концепция "Мориарти":** короткие, динамичные видео (1-3 минуты) с демонстрацией реальных кейсов пробива. Например: "Как найти владельца авто по номеру за 60 секунд", "Проверяем продавца на Авито через нашего бота". Фокус на вау-эффекте. | $1,000/мес (монтаж, озвучка) |
| **SEO-оптимизированный блог** | Создание публичного сайта (раздел 16 в ТЗ) и регулярное наполнение его статьями под ключевые запросы ("пробив по номеру", "osint бот", "купить логи банков"). Цель — занять топ-10 в Google/Yandex. | $500/мес (копирайтинг) |
| **TikTok / Instagram Reels** | Аналогично YouTube, но ещё более короткие и вирусные видео. Демонстрация одной функции за 15-30 секунд. Цель — максимальный охват и перелив трафика в Telegram-канал. | $300/мес (контент) |

### Уровень 3: Доминирование (6+ месяцев)

**Задача:** Стать лидером ниши и создать бренд.

| Канал | Описание | Бюджет |
| :--- | :--- | :--- |
| **Создание собственного медиа** | Развитие Telegram-канала до уровня полноценного СМИ в нише OSINT. Публикация новостей, инсайдов, интервью с экспертами. | $3,000+/мес |
| **Разработка вирусных инструментов** | Создание бесплатных, но полезных мини-ботов (например, бот для проверки сложности пароля, бот для генерации временной почты), которые будут содержать ссылку на основной продукт. | $1,000 - $5,000 (разработка) |
| **Партнёрская программа (Marketer Bot)** | Активное развитие платформы для маркетологов (раздел 8 в ТЗ), создание обучающих материалов, проведение вебинаров, конкурсов для лучших партнёров. | % от дохода |

## 3. Техническая реализация отслеживания

- **UTM-метки:** Все внешние ссылки на Mirror Bot должны содержать UTM-метки для отслеживания источника, канала и кампании. Пример: `t.me/YourMirrorBot?start=utm_source-youtube_utm_medium-video_utm_campaign-moriarty_case1`.
- **Таблица `traffic_sources`:** В БД должна быть таблица для хранения информации об источниках трафика, привязанная к пользователю.
- **Аналитика в Admin Panel:** В Admin Panel (раздел 12.11) должен быть отчёт по эффективности каналов привлечения, показывающий количество регистраций, пополнений и LTV для каждого источника.
