## Детальный план по каналам

### Форумы (Lolz / XSS / BHF)

**Почему только крупные:** Мелкие форумы (Античат и др.) дают в 13 раз меньше трафика при тех же затратах времени. Фокус исключительно на трёх крупных платформах.

**Lolz.live — главный приоритет:**
- Тема в разделе "Услуги" (бесплатно) → 200-500 просмотров/день
- Закреп темы на неделю ($50-100) → 2,000-5,000 просмотров
- Маркетплейс: продажа услуг бота как товара (5-10% комиссия форуму)
- Подпись в профиле: каждый комментарий несёт рекламу

**XSS.is — элитная аудитория:**
- Тема в разделе "Сервисы" (нужна репутация)
- Баннер: $100-300/мес
- Конверсия 5-10% — самая высокая среди форумов

**BHF.io — международный охват:**
- Тема в "Tools & Services"
- Бесплатный триал для участников форума → отзывы → репутация

### Вирусный контент

**Формат 1 — "Проверил себя" (самый вирусный):**
Видео 30-60 сек: "Ввёл свой номер в этот бот и вот что он нашёл..." Показываешь результат с заблюренными данными. Публикуется в TikTok, YouTube Shorts, Telegram. Такие видео набирают 100k-1M просмотров.

**Формат 2 — Скриншот-провокация:**
"Этот бот нашёл мой адрес, работу и все соцсети только по номеру телефона 😱" → одновременная публикация в 50-100 чатах.

**Формат 3 — Кейс с историей:**
"Проверил партнёра по бизнесу — нашёл 3 судимости" или "Нашёл мошенника через этот бот". Истории репостятся сами по себе.

**Дистрибуция:** TikTok, YouTube Shorts, Reddit (r/OSINT, r/russia), 50-100 Telegram-чатов одновременно.

### Маркетологи + Зеркала

Это **главный двигатель роста** в долгосрочной перспективе. Каждый маркетолог — это отдельный источник трафика, который работает 24/7.

**Как привлечь маркетологов:**
1. Пост на Lolz/XSS: "Зарабатывай 7% с каждого пополнения — создай свой Mirror Bot"
2. Посев в каналах арбитражников ($200-300)
3. Личные переговоры с владельцами Telegram-каналов по OSINT
4. Объявление в чатах по партнёркам и заработку

**Что получает маркетолог:**
- Свой Mirror Bot с уникальным именем
- 7% с каждого пополнения привлечённых пользователей
- Панель статистики в Marketer Bot
- Промокод для дополнительного привлечения

**Ограничения (защита от злоупотреблений):**
- Нельзя пользоваться своим ботом самому (self-referral блокируется)
- Вывод только через запрос в Marketer Bot

### Арбитраж трафика

**Воронка:** Push-уведомление → Лендинг → Telegram Bot

**Площадки:**
- `PropellerAds` — Push, $100 минимум, глобальный охват
- `ClickAdilla` — Push + Pop, $50 минимум, много RU трафика
- `Adsterra` — Pop-under, $100 минимум

**Лендинг:** Одностраничный сайт с заголовком "Узнай всё о любом человеке за 30 секунд" + кнопка "Попробовать бесплатно" → переход в Telegram Bot.

**Оптимизация:** После теста на $200-500 снизить CAC с $5.93 до $1-2 через A/B тест заголовков.

### Telegram Ads (Официальная реклама)

**Минимальный бюджет:** €2,000 (официальный минимум Telegram).

**Таргетинг:**
- Каналы по теме "Безопасность"
- Каналы по теме "Технологии"
- Каналы по теме "Криптовалюта"
- Каналы по теме "Заработок"

**Формат:** Текстовое сообщение до 160 символов + кнопка. Показывается внизу ленты канала.

**Важно:** Telegram модерирует рекламу. Избегать слов "пробив", "слежка". Использовать нейтральные формулировки: "Проверка информации", "OSINT-инструмент".

### Stories у микро-блогеров

Stories воспринимаются как личная рекомендация, а не реклама. Конверсия выше, чем у постов.

**Как найти блогеров:** TGStat.ru → личные аккаунты с 1,000-10,000 подписчиков в нише OSINT/безопасность. Стоимость: $10-50 за Stories.

**Скрипт для блогера:** "Я сам пользуюсь этим ботом уже месяц — нашёл через него информацию о [кейс]. Вот ссылка, первый запрос бесплатно."

## Главные риски и как их избежать

| Риск | Вероятность | Митигация |
|---|---|---|
| Маркетологи не приходят | Средняя | Увеличить комиссию до 10% на старте, дать бонус первым 10 |
| Telegram банит бота | Низкая | Держать 2-3 резервных бота, не использовать запрещённые слова |
| Конкуренты копируют модель | Высокая | Скорость роста и сеть маркетологов — главное преимущество |
| Отток выше 15% | Средняя | Добавить подписочную модель, email-рассылки, push-уведомления |
| Платёжная система блокирует | Низкая | Использовать несколько платёжных систем (CryptoPay + Cryptomus) |
