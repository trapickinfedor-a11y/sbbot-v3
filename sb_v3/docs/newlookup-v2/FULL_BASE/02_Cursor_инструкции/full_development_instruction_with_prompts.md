# Полная инструкция по разработке Newlookup с промтами для Cursor

Это чеклист из 17 задач для написания всего бэкенда. Выполняй шаги последовательно. Каждая задача содержит готовый промт, который нужно скопировать и вставить в Cursor.

**Главное правило:** Перед каждым промтом в Cursor **обязательно** выделяй весь текст файла `newlookup_srs_v12_full.md` (Ctrl+A) и добавляй его в чат (`@` или аналогичная функция), чтобы AI всегда был в контексте.

---

**Цель:** Подготовить скелет проекта, настроить конфигурацию и создать все модели базы данных.

-   [ ] **Задача 2: Написать файл конфигурации**

-   [ ] **Задача 3: Написать модели базы данных**

    > **Промт для Cursor:**
    > «Напиши код для моделей SQLAlchemy. Раздели все модели из раздела 3 этого ТЗ на 3 файла, как указано в файловой структуре (`user_related.py`, `product_related.py`, `system.py`). Используй SQLAlchemy 2.0 с аннотациями типов. Код моделей из раздела 3.2 используй как точный образец.»

-   [ ] **Задача 4: Настроить подключение к БД**
