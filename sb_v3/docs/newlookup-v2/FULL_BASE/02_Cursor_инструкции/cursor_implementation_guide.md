# Newlookup — Полное Руководство по Реализации в Cursor

**Версия:** 1.0
**Дата:** 13.03.2026

**Задача:** Этот документ — ваш главный навигатор. Он содержит пошаговый план реализации всей системы Newlookup с использованием Cursor IDE. Следуйте этому плану, чтобы обеспечить быструю, качественную и консистентную разработку.

---

## 1. Философия Разработки

1.  **Cursor-First:** Мы не пишем код руками. Мы пишем промты и даём их Cursor. Руками мы только исправляем мелкие ошибки.
2.  **Prompt-Driven Development (PDD):** Каждый модуль, сервис или компонент начинается с промта. Промт — это мини-ТЗ.
3.  **Итеративность:** Не пытайтесь создать всё за один раз. Двигайтесь маленькими шагами: Модель → Сервис → Роут → Хендлер → UI.
4.  **Копируй-Вставляй:** Все документы в этом пакете (особенно `models_and_services.md`, `api_routes_full.md` и т.д.) созданы так, чтобы вы могли просто копировать из них код и вставлять в Cursor.

**Промт 1.2: Создание моделей SQLAlchemy**
> Скопируй код моделей из `models_and_services.md` и создай соответствующие файлы в `/app/models`. Убедись, что все импорты и зависимости корректны.

**Промт 1.3: Настройка подключения к БД**
> В файле `/app/db/session.py` напиши код для создания асинхронной сессии SQLAlchemy, используя данные из `.env` файла (PostgreSQL).

### Этап 2: Ядро: Пользователи и Auth

**Промт 2.1: Создание сервиса пользователей**
> В файле `/app/services/user_service.py` создай класс `UserService` со следующими методами: `get_user_by_id`, `get_user_by_telegram_id`, `create_user`, `update_user_balance`. Используй SQLAlchemy-модель `User` и Pydantic-схему `UserCreate`.

**Промт 2.2: Создание роутов для пользователей**
> В файле `/app/api/v1/routes/users.py` создай FastAPI роутер с эндпоинтами для получения и создания пользователей, используя `UserService`.
