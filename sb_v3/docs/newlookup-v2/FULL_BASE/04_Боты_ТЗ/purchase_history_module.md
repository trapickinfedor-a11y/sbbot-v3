## Модуль: История Покупок и Архив v2.0 (Детализация для Cursor)

**Задача:** Создать исчерпывающее руководство для Cursor по реализации модуля истории покупок. Документ включает SQL-изменения, детальное описание API, пошаговые сценарии для Telegram-бота и конкретные промты.

---

### 1. Обзор Функционала

1.  **Просмотр Истории:** Пользователь может просматривать все свои покупки с пагинацией.
2.  **Фильтрация:** Покупки можно фильтровать по категориям товаров (`Selfreg BA`, `Logs`, etc.) и по конкретным продавцам.
3.  **Архив-Канал:** Пользователь может настроить автоматическую отправку всех своих покупок в личный, приватный Telegram-канал.
4.  **Закрепление:** Последняя покупка всегда закрепляется в чате с ботом для быстрого доступа.

---

### 2. Изменения в Базе Данных (SQL)

Нужно добавить одно поле в таблицу `users`.

```sql
-- Добавляем поле для хранения ID канала-архива
ALTER TABLE users ADD COLUMN archive_channel_id BIGINT DEFAULT NULL;

-- Добавляем индекс для быстрого поиска
CREATE INDEX idx_users_archive_channel_id ON users (archive_channel_id);
```

### 3. API Эндпоинты (FastAPI)

#### **3.1. Получение Истории Покупок**

*   **Эндпоинт:** `GET /api/v1/orders/my`
*   **Защита:** `Depends(get_current_user)`
*   **Query-параметры:**
    *   `page: int = 1`
    *   `limit: int = 10`
    *   `category_id: Optional[int] = None`
    *   `seller_id: Optional[int] = None`
*   **Логика:**
    1.  Получить `user_id` из токена.
    2.  Сделать запрос к БД в таблицу `orders`, фильтруя по `buyer_id = user_id`.
    3.  Если переданы `category_id` или `seller_id`, добавить соответствующие `WHERE` условия (с `JOIN` на `products` и `sellers`).
    4.  Применить пагинацию (`LIMIT` и `OFFSET`).
    5.  Вернуть список заказов с вложенными объектами товара и продавца.
*   **Pydantic-схемы:**

    ```python
    class SellerInfo(BaseModel):
        id: int
        username: str

    class ProductInfo(BaseModel):
        id: int
        name: str
        category_name: str

    class OrderHistoryItem(BaseModel):
        id: int
        amount: float
        status: str
        created_at: datetime
        seller: SellerInfo
        product: ProductInfo

    class PaginatedOrderHistory(BaseModel):
        items: List[OrderHistoryItem]
        total: int
        page: int
        limit: int
    ```

#### **3.2. Настройка Архива-Канала**

*   **Эндпоинт:** `POST /api/v1/users/me/set-archive-channel`
*   **Защита:** `Depends(get_current_user)`
*   **Тело запроса (Pydantic):**

    ```python
    class SetArchiveChannelRequest(BaseModel):
        channel_id: int
    ```
*   **Логика:**
    1.  Получить `user_id` из токена.
    2.  Обновить поле `archive_channel_id` для данного пользователя.
    3.  Вернуть `{"status": "ok"}`.

### 4. Логика в Telegram-Боте (aiogram 3)

#### **4.1. Раздел "Мои Покупки"**

1.  **Хендлер:** Реагирует на `F.text == "📦 Мои покупки"`.
2.  **Действие:** Делает запрос к `GET /api/v1/orders/my`.
3.  **Формирование сообщения:**
    *   Создает `InlineKeyboardBuilder`.
    *   Добавляет кнопки фильтров: `[🗂 По категориям]`, `[👨‍💼 По продавцам]`.
    *   Для каждого заказа из ответа API формирует текст и кнопку `[Детали]`.
    *   Добавляет кнопки пагинации (`<<`, `>>`).

#### **4.2. Фильтрация**

1.  **Хендлер:** Реагирует на `CallbackQuery(F.data.startswith("history_filter:"))`.
2.  **Логика:**
    *   При `history_filter:category` — делает запрос к API для получения списка категорий, по которым у юзера есть покупки, и показывает их как инлайн-кнопки.
    *   При `history_filter:seller` — аналогично для продавцов.
    *   При выборе конкретной категории/продавца — делает запрос к `GET /api/v1/orders/my` с нужным `category_id` или `seller_id` и обновляет сообщение.

#### **4.3. Настройка Архива**

1.  **Хендлер:** Реагирует на `F.text == "📁 Настроить архив"`.
2.  **Действие:** Отправляет инструкцию (создать канал, добавить бота, переслать сообщение).
3.  **Хендлер на пересланное сообщение:**
    *   Реагирует на `F.forward_from_chat`.
    *   Проверяет, что `forward_from_chat.type == 'channel'`.
    *   Извлекает `channel_id = F.forward_from_chat.id`.
    *   Делает запрос к `POST /api/v1/users/me/set-archive-channel`.
    *   Отправляет пользователю сообщение об успешной настройке.
