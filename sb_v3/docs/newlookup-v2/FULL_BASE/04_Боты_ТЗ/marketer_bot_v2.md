## Marketer Bot v2.1 — Платформа Ботов-Клонов

**Задача:** Предоставить маркетологам простой и мощный инструмент для привлечения покупателей через создание собственных ботов-клонов (прокси). Логика многоуровневого маркетинга и реферальных ссылок **полностью удалена**.

---

### 1. Основная Логика

1.  **Кто такой маркетолог?** Любой пользователь, который хочет зарабатывать на привлечении трафика.
2.  **Как он зарабатывает?** Маркетолог создаёт своего бота-клона. Все покупки, совершённые через этого бота, приносят ему **фиксированную комиссию 10%** от суммы покупки.
3.  **Как это работает?** Маркетолог регистрируется в `@MarketerBot`, создаёт там своего бота (`@MySuperShopBot`), получает на него ссылку и начинает её распространять. Весь трафик, пришедший через `@MySuperShopBot`, автоматически привязывается к этому маркетологу.

### 2. Функционал Marketer Bot

#### 2.1. Дашборд

После старта бот показывает главный дашборд:

| Метрика | Значение |
| :--- | :--- |
| 🤖 Мои боты | 3 |
| 👥 Покупателей сегодня | 12 |
| 🛒 Продаж сегодня | 4 |
| 💰 Заработано сегодня | $25.60 |
| 💵 Баланс для вывода | $450.00 |

**Кнопки:** `[🤖 Мои боты]`, `[📊 Статистика]`, `[💰 Финансы]`, `[⚙️ Настройки]`

#### 2.2. Управление Ботами-Клонами

В разделе `[🤖 Мои боты]` маркетолог может:
*   **Создать нового бота:**
    1.  Нажимает `[➕ Создать бота]`.
    2.  Бот даёт инструкцию: "Создайте бота в `@BotFather`, получите токен и пришлите его мне".
    3.  Маркетолог присылает токен.
    4.  Бот проверяет токен, сохраняет его и отвечает: "✅ Бот `@MyNewShopBot` успешно создан! Ваша ссылка для привлечения: `t.me/MyNewShopBot`".
*   **Настроить бота:** Для каждого своего бота можно настроить:
    *   **Приветственное сообщение:** Текст, который увидит новый пользователь.
    *   **Промо-материалы:** Загрузить свои картинки/видео для каталога.
*   **Посмотреть статистику по боту:** Сколько людей пришло, сколько купило через конкретного бота.

#### 2.3. Статистика и Финансы

*   **`[📊 Статистика]`:** Детальные графики: регистрации, продажи, конверсия. Фильтры по дням/неделям/месяцам и по конкретным ботам.
*   **`[💰 Финансы]`:**
    *   Просмотр баланса.
    *   История начислений (каждая комиссия как отдельная транзакция).
    *   Запрос на вывод средств (минимальная сумма $100).

### 3. Антифрод-система

Так как реферальных ссылок больше нет, антифрод упрощается. Основной фокус — на аномальной активности внутри одного бота-клона.

*   **Обнаружение накрутки:** Если через одного бота-клона регистрируется аномально много пользователей с одного IP-адреса или подсети, система отправляет уведомление администратору.
*   **Анализ транзакций:** Если все покупки в боте-клоне совершаются на маленькие суммы или одним и тем же покупателем, это повод для проверки.
