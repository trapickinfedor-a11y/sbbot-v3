## UX-Сценарии Покупателя — Пошаговые Флоу

**Задача:** Детально описать путь пользователя (Customer Journey) при покупке каждого основного типа товара. Это поможет разработчикам понять логику, а тестировщикам — проверить её.

---

### Сценарий 1: Покупка товара "In Stock" (например, Selfreg BA)

**Цель:** Максимально быстрый и простой флоу. Пользователь должен получить товар за ~15 секунд.

| Шаг | Действие пользователя | Ответ системы (Mirror Bot) |
| :--- | :--- | :--- |
| 1 | Нажимает `[🗂️ Каталог]` | Показывает список категорий. |
| 2 | Выбирает категорию `[Selfreg BA]` | Показывает список товаров в этой категории с ценами. |
| 3 | Выбирает товар `[Chase Bank Selfreg - $50]` | Показывает карточку товара: описание, рейтинг продавца, кол-во в наличии. Кнопки: `[✅ Купить]`, `[❤️ В вишлист]`, `[🛒 Добавить в корзину]`. |
| 4 | Нажимает `[✅ Купить]` | Показывает окно подтверждения: `"Вы уверены, что хотите купить Chase Bank Selfreg за $50?"`. Кнопки: `[Да, купить]`, `[Отмена]`. |
| 5 | Нажимает `[Да, купить]` | **Проверка баланса:**<br>- **Если баланс достаточен:** Списывает $50. Переходит к шагу 6.<br>- **Если баланс недостаточен:** `"На вашем балансе недостаточно средств. Пополнить?"` Кнопки: `[💰 Пополнить]`, `[Отмена]`. |
| 6 | (Баланс достаточен) | **Транзакция:** Создает заказ, списывает деньги, отправляет уведомление продавцу.<br>Сообщение пользователю: `"✅ Оплата прошла успешно! Готовим ваш товар..."` (с анимацией загрузки). |
| 7 | - | **Выдача товара:** Через 1-3 секунды сообщение обновляется. Показывает данные товара (логин, пароль) и прикрепленный файл. Кнопки: `[⭐️ Оставить отзыв]`, `[❓ Открыть спор]`. |

### Сценарий 2: Покупка товара "Per Order" (например, Credit Score)

**Цель:** Четко и прозрачно информировать пользователя о статусе его заказа, который выполняется вручную.

| Шаг | Действие пользователя | Ответ системы (Mirror Bot) |
| :--- | :--- | :--- |
| 1-5 | (Аналогично сценарию 1) | ... |
| 6 | (Баланс достаточен) | **Создание заказа:** Создает заказ со статусом `PENDING_WORKER`. Деньги **холдируются** (эскроу).<br>Сообщение: `"✅ Заказ принят! Ищем свободного воркера для выполнения..."` |
| 7 | - | **Воркер взял заказ:** Через 1-5 минут приходит уведомление: `"👨‍💻 Воркер @worker_alex начал выполнять ваш заказ. Ожидаемое время выполнения: 15 минут."` |
| 8 | - | **Воркер выполнил заказ:** Приходит уведомление с результатом (например, PDF-файл с отчетом).<br>`"✅ Ваш заказ #12345 выполнен!"`<br>Кнопки: `[👍 Подтвердить выполнение]`, `[👎 Открыть спор (24ч)]`. |
| 9 | Нажимает `[👍 Подтвердить выполнение]` | **Завершение:** Деньги переводятся с холда на баланс продавца. Заказ закрывается.<br>Сообщение: `"Спасибо за подтверждение! Не забудьте оставить отзыв."`. |
| 10 | (Если не нажимает 24ч) | **Авто-завершение:** Через 24 часа заказ автоматически закрывается. Деньги переводятся продавцу. |

### Сценарий 3: Покупка товара с использованием Корзины

**Цель:** Позволить пользователю купить несколько товаров от разных продавцов за одну транзакцию.

| Шаг | Действие пользователя | Ответ системы (Mirror Bot) |
| :--- | :--- | :--- |
| 1 | (На карточке товара) Нажимает `[🛒 Добавить в корзину]` | Товар добавляется в корзину. Кнопка `[🛒 Корзина (1)]` в главном меню обновляется. |
| 2 | (Повторяет для другого товара) | Кнопка `[🛒 Корзина (2)]` обновляется. |
| 3 | Нажимает `[🛒 Корзина (2)]` | Показывает список товаров в корзине с общей суммой.<br>`1. Chase Bank Selfreg - $50`<br>`2. Netflix Premium - $10`<br>**Итого: $60**<br>Кнопки: `[✅ Оплатить всё]`, `[✏️ Редактировать]`, `[❌ Очистить]`. |
| 4 | Нажимает `[✅ Оплатить всё]` | **Проверка баланса:** Списывает $60.<br>Создает **один родительский заказ** и **два дочерних под-заказа** для каждого продавца. |
| 5 | - | Выдает товары по мере их готовности (как в сценариях 1 и 2). |
