## Введение

В современном бизнесе эффективное управление взаимоотношениями с клиентами (CRM) является ключевым фактором успеха. CRM-системы позволяют централизовать данные о клиентах, автоматизировать процессы продаж и маркетинга, а также получать ценную аналитику. Однако многие готовые решения могут быть дорогостоящими и избыточными для малого и среднего бизнеса.

**NocoDB** — это open-source no-code платформа, которая превращает любую базу данных (MySQL, PostgreSQL, SQLite и др.) в умную электронную таблицу, похожую на Airtable. С помощью NocoDB можно создать гибкую и масштабируемую CRM-систему, полностью адаптированную под ваши бизнес-процессы, без написания единой строчки кода [[1]](https://nocodb.com).

Это руководство проведет вас через все этапы создания полнофункциональной CRM в NocoDB, включая управление сотрудниками, отслеживание маркетинговых кампаний, ведение сделок и построение аналитических дашбордов.

### Что вы получите в итоге

| Компонент | Назначение |
|---|---|
| **6 связанных таблиц** | Сотрудники, Клиенты, Сделки, Задачи, Маркетинговые кампании, Взаимодействия |
| **4 типа представлений** | Канбан-доска, Календарь, Форма для лидов, Галерея команды |
| **Аналитический дашборд** | KPI-метрики, воронка продаж, источники клиентов, динамика выручки |
| **Автоматизация (Workflows)** | Уведомления о новых сделках, автосоздание задач при смене стадии |

## Часть 1: Настройка базовой структуры (Таблицы)

Основа любой CRM — это хорошо структурированные данные. Мы создадим шесть основных таблиц, которые будут хранить всю необходимую информацию. Для каждой таблицы нажмите `+ New Table` в левой панели вашего проекта (Base) в NocoDB.

### Таблица 1: «Сотрудники» (Employees)

Эта таблица является центральным справочником вашей команды. Все остальные таблицы будут ссылаться на неё для назначения ответственных.

**Инструкция:** Создайте таблицу `Сотрудники` и добавьте следующие поля, нажимая `+` в заголовке таблицы и выбирая соответствующий `Field Type`:

| Название поля | Тип поля (Field Type) | Настройки / Описание |
|---|---|---|
| `ID сотрудника` | `ID` | Генерируется автоматически. |
| `ФИО` | `Single line text` | Полное имя сотрудника. Сделайте это поле **Display Value**. |
| `Должность` | `Single line text` | Например, "Менеджер по продажам". |
| `Email` | `Email` | Рабочий email. |
| `Телефон` | `Phone` | Контактный номер. |
| `Отдел` | `Single select` | Добавьте опции: "Продажи", "Маркетинг", "Руководство", "Поддержка". |
| `Фото` | `Attachment` | Фотография сотрудника для галереи. |

### Таблица 2: «Клиенты» (Clients)

Здесь будет храниться вся информация о ваших клиентах и лидах. Это главный реестр всех контактов.

| Название поля | Тип поля (Field Type) | Настройки / Описание |
|---|---|---|
| `ID клиента` | `ID` | Генерируется автоматически. |
| `Название / ФИО` | `Single line text` | Название компании или ФИО частного лица. |
| `Статус клиента` | `Single select` | Опции: "Лид", "Потенциальный", "Активный", "Неактивный". |
| `Тип клиента` | `Single select` | Опции: "B2B", "B2C". |
| `Email` | `Email` | Основной контактный email. |
| `Телефон` | `Phone` | Основной контактный телефон. |
| `Сайт` | `URL` | Веб-сайт клиента. |
| `Источник` | `Single select` | Опции: "Реклама", "Рекомендация", "Сайт", "Выставка", "Холодный звонок". |
| `Город / Регион` | `Single line text` | Географическое расположение клиента. |
| `Примечания` | `Long text` | Любые дополнительные заметки о клиенте. |
| `Дата добавления` | `Date` | Когда клиент был добавлен в систему. |

### Таблица 3: «Сделки» (Deals)

Для отслеживания всего процесса продаж — от первого контакта до закрытия.

| Название поля | Тип поля (Field Type) | Настройки / Описание |
|---|---|---|
| `ID сделки` | `ID` | Генерируется автоматически. |
| `Название сделки` | `Single line text` | Краткое описание, например, "Разработка сайта для ООО Ромашка". |

| `Стадия` | `Single select` | Опции воронки: "Новая", "Квалификация", "Переговоры", "Выставлен счет", "Успешно закрыта", "Проиграна". |
| `Вероятность, %` | `Number` | Вероятность успешного закрытия (0-100). |
| `Дата создания` | `Date` | Когда сделка была открыта. |
| `Дата закрытия` | `Date` | Планируемая или фактическая дата завершения. |
| `Причина проигрыша` | `Single select` | Опции: "Цена", "Конкурент", "Не актуально", "Нет ответа". |

### Таблица 4: «Задачи» (Tasks)

Для управления задачами сотрудников, связанными с клиентами и сделками.

| Название поля | Тип поля (Field Type) | Настройки / Описание |

## Часть 2: Связывание таблиц для создания единой системы

Теперь необходимо связать таблицы между собой. Это превратит набор отдельных таблиц в полноценную реляционную базу данных. Связывание происходит с помощью поля типа **Link to another record** [[2]](https://nocodb.com/docs/product-docs/fields/field-types/links-based/links).

### Схема связей

```
Сотрудники ──┬──> Сделки (Ответственный)
             ├──> Клиенты (Ответственный)
             ├──> Задачи (Исполнитель)
             ├──> Маркетинговые кампании (Ответственный)
             └──> Взаимодействия (Сотрудник)

Клиенты ────┬──> Сделки (Клиент)
             ├──> Задачи (Связано с клиентом)
             └──> Взаимодействия (Клиент)

Сделки ─────└──> Задачи (Связано со сделкой)
```

### Пошаговая настройка связей

**Связь 1: Сделки → Клиенты**

1.  Откройте таблицу **«Сделки»** и нажмите `+` для добавления нового поля.
2.  Назовите поле `Клиент` и выберите тип `Link to another record`.
3.  В поле `Table` выберите **«Клиенты»**. NocoDB автоматически создаст обратную связь в таблице «Клиенты».
4.  Нажмите `Save Field`.

**Связь 2: Сделки → Сотрудники**

1.  В таблице **«Сделки»** создайте поле `Ответственный` с типом `Link to another record`.
2.  Свяжите с таблицей **«Сотрудники»** и сохраните.

**Связь 3: Клиенты → Сотрудники**

1.  В таблице **«Клиенты»** создайте поле `Ответственный` с типом `Link to another record`.
2.  Свяжите с таблицей **«Сотрудники»** и сохраните.

**Связь 4: Задачи → Сделки, Клиенты, Сотрудники**

1.  В таблице **«Задачи»** создайте три поля с типом `Link to another record`:
    *   `Связано со сделкой` → таблица **«Сделки»**
    *   `Связано с клиентом` → таблица **«Клиенты»**
    *   `Исполнитель` → таблица **«Сотрудники»**

**Связь 5: Взаимодействия → Клиенты, Сотрудники**

1.  В таблице **«Взаимодействия»** создайте два поля:
    *   `Клиент` → таблица **«Клиенты»**
    *   `Сотрудник` → таблица **«Сотрудники»**

**Связь 6: Маркетинговые кампании → Сотрудники**

1.  В таблице **«Маркетинговые кампании»** создайте поле `Ответственный` → таблица **«Сотрудники»**.

После настройки всех связей вы сможете, например, открыть карточку любого клиента и сразу увидеть все его сделки, задачи и историю взаимодействий в одном месте.

## Часть 3: Визуализация данных с помощью представлений (Views)

NocoDB поддерживает пять типов представлений [[3]](https://nocodb.com/docs/product-docs/views): **Grid** (таблица), **Kanban** (канбан-доска), **Gallery** (галерея), **Form** (форма) и **Calendar** (календарь). Каждое представление — это независимый «вид» на данные одной таблицы с собственными фильтрами, сортировкой и видимостью полей.

### Представление 1: Канбан-доска для воронки продаж

Канбан-доска — идеальный инструмент для визуализации и управления воронкой продаж. Вы видите все сделки, сгруппированные по стадиям, и можете перетаскивать их мышью.

**Инструкция:**
1.  Откройте таблицу **«Сделки»**.
2.  В левой панели нажмите `+` рядом с разделом Views и выберите `Kanban`.
3.  В настройках (`Stacking Column`) выберите поле **«Стадия»**.
4.  Назовите представление «Воронка продаж» и сохраните.

Теперь каждая колонка на доске соответствует стадии сделки. Перетаскивание карточки автоматически меняет значение поля «Стадия» в записи.

### Представление 2: Календарь задач

Позволяет видеть все задачи сотрудников в виде календаря по датам дедлайна.

**Инструкция:**
1.  Откройте таблицу **«Задачи»**.
2.  Создайте новое представление типа `Calendar`.
3.  В настройках (`Date Column`) выберите **«Срок выполнения»**.
4.  Назовите «Календарь задач».

Вы можете переключаться между видами «День», «Неделя» и «Месяц» для удобного планирования.

### Представление 3: Форма для сбора лидов

Публичная форма, которую можно разместить на сайте или отправить клиенту для самостоятельного заполнения. Данные автоматически попадают в таблицу «Клиенты».

**Инструкция:**
1.  Откройте таблицу **«Клиенты»**.
2.  Создайте новое представление типа `Form`.
3.  В редакторе формы перетащите в форму только нужные поля: `Название / ФИО`, `Email`, `Телефон`, `Источник`.
4.  Отметьте `Email` и `Название / ФИО` как обязательные (значок `*`).
5.  Нажмите `Share Form` и скопируйте публичную ссылку.

### Представление 4: Галерея команды

Наглядное представление сотрудников с фотографиями.

**Инструкция:**
1.  Откройте таблицу **«Сотрудники»** и убедитесь, что поле `Фото` (тип `Attachment`) заполнено.
2.  Создайте новое представление типа `Gallery`.
3.  В настройках (`Cover Image Column`) выберите **«Фото»**.

### Представление 5: Фильтрованные Grid-представления

Создайте несколько Grid-представлений с разными фильтрами для быстрого доступа к нужным данным:

| Название представления | Таблица | Фильтр |
|---|---|---|
| «Мои задачи» | Задачи | `Исполнитель` = текущий пользователь |
| «Активные сделки» | Сделки | `Стадия` не равно "Успешно закрыта" и "Проиграна" |
| «Активные кампании» | Маркетинговые кампании | `Статус` = "Активна" |
| «Новые лиды» | Клиенты | `Статус клиента` = "Лид" |

## Часть 4: Построение аналитических дашбордов

Дашборды в NocoDB — это интерактивные панели с виджетами (графиками, диаграммами, метриками), которые визуализируют данные из ваших таблиц [[4]](https://nocodb.com/docs/product-docs/dashboards). Дашборды доступны на планах **Plus** и **Business** в облачной версии NocoDB.

### Создание дашборда

1.  В левом меню нажмите `+ New` и выберите `Dashboard`.
2.  Введите название, например, «Главный дашборд CRM», и нажмите `Create Dashboard`.
3.  Нажмите `Edit Dashboard` в правом верхнем углу, чтобы войти в режим редактирования.

### Виджет 1: Объем продаж (Number)

Показывает общую сумму всех успешно закрытых сделок.

1.  На панели виджетов выберите `Number`.
2.  Настройки:
    *   **Table**: «Сделки»
    *   **Operation**: `Sum`
    *   **Column**: «Сумма»
    *   **Filter**: «Стадия» `is` «Успешно закрыта»
3.  Заголовок виджета: «Объем продаж».

### Виджет 2: Количество активных сделок (Number)

1.  Добавьте виджет `Number`.
2.  Настройки:
    *   **Table**: «Сделки»
    *   **Operation**: `Count`
    *   **Filter**: «Стадия» `is not` «Успешно закрыта» и «Стадия» `is not` «Проиграна»
3.  Заголовок: «Активных сделок».

### Виджет 3: Воронка продаж (Pie Chart / Donut Chart)

Показывает распределение сделок по стадиям.

1.  Добавьте виджет `Donut Chart`.
2.  Настройки:
    *   **Table**: «Сделки»
    *   **Dimension (группировка)**: «Стадия»
    *   **Metric**: `Count of records`
3.  Заголовок: «Воронка продаж».

### Виджет 4: Источники клиентов (Bar Chart)

Показывает, какие маркетинговые каналы приносят больше всего клиентов.

1.  Добавьте виджет `Bar Chart`.
2.  Настройки:
    *   **Table**: «Клиенты»
    *   **X-Axis**: «Источник»
    *   **Y-Axis**: `Count of records`
3.  Заголовок: «Источники клиентов».

### Виджет 5: Динамика продаж по месяцам (Line Chart)

Показывает, как менялась сумма успешных сделок во времени.

1.  Добавьте виджет `Line Chart`.
2.  Настройки:
    *   **Table**: «Сделки»
    *   **X-Axis**: «Дата закрытия» (сгруппировать по месяцам)
    *   **Y-Axis**: `Sum` of «Сумма»
    *   **Filter**: «Стадия» `is` «Успешно закрыта»
3.  Заголовок: «Динамика продаж».

### Виджет 6: Задачи по статусам (Pie Chart)

Показывает нагрузку команды и состояние задач.

1.  Добавьте виджет `Pie Chart`.
2.  Настройки:
    *   **Table**: «Задачи»
    *   **Dimension**: «Статус»
    *   **Metric**: `Count of records`
3.  Заголовок: «Задачи по статусам».

### Виджет 7: Бюджет маркетинговых кампаний (Bar Chart)

Сравнивает запланированный и потраченный бюджет по кампаниям.

1.  Добавьте виджет `Bar Chart`.
2.  Настройки:
    *   **Table**: «Маркетинговые кампании»
    *   **X-Axis**: «Название кампании»
    *   Добавьте две серии данных: `Sum` of «Бюджет» и `Sum` of «Потрачено»
3.  Заголовок: «Бюджет кампаний».

После настройки всех виджетов нажмите `Save` и выйдите из режима редактирования. Вы можете поделиться дашбордом с командой, нажав `Share` и включив публичный доступ.

## Часть 5: Автоматизация процессов с помощью Workflows

**Workflows** в NocoDB позволяют автоматизировать задачи, реагируя на события в вашей базе данных [[5]](https://nocodb.com/docs/workflows). Каждый Workflow состоит из **триггера** (что запускает автоматизацию) и **действий** (что должно произойти).

### Workflow 1: Уведомление о новой сделке по Email

Когда менеджер создает новую сделку, руководитель получает уведомление на почту.

**Настройка:**
1.  Создайте новый Workflow (`+ New` → `Workflow`). Назовите «Уведомление: Новая сделка».
2.  **Триггер**: выберите `Record created` → Table: «Сделки».
3.  **Действие**: нажмите `+` и выберите `Send email`.
4.  Настройте письмо:
    *   **To**: email руководителя
    *   **Subject**: `Новая сделка: {{$trigger.fields['Название сделки']}}`
    *   **Body**: `Создана новая сделка на сумму {{$trigger.fields['Сумма']}}. Ответственный: {{$trigger.fields['Ответственный']}}.`
5.  Включите Workflow (тумблер в правом верхнем углу).

### Workflow 2: Автосоздание задачи при смене стадии сделки

Когда сделка переходит на стадию «Переговоры», система автоматически создает задачу «Подготовить КП».

**Настройка:**
1.  Создайте Workflow «Автозадача: Переговоры».
2.  **Триггер**: `Record updated` → Table: «Сделки» → Condition: «Стадия» `changed to` «Переговоры».
3.  **Flow-узел**: добавьте `If / else` → условие: `{{$trigger.fields['Стадия']}}` `equals` «Переговоры».
4.  В ветке `True` добавьте действие `Create record`:
    *   **Table**: «Задачи»
    *   **Название задачи**: `Подготовить КП: {{$trigger.fields['Название сделки']}}`
    *   **Исполнитель**: `{{$trigger.fields['Ответственный']}}`
    *   **Тип задачи**: «Подготовка КП»
    *   **Приоритет**: «Высокий»
5.  Включите Workflow.

### Workflow 3: Напоминание о просроченных задачах

Каждый день в 9:00 система проверяет просроченные задачи и отправляет напоминания.

**Настройка:**
1.  Создайте Workflow «Напоминание: Просроченные задачи».
2.  **Триггер**: `Scheduled time` → настройте расписание «Каждый день в 9:00».
3.  **Действие**: `List records` → Table: «Задачи» → Filter: «Срок выполнения» `is before` `today` AND «Статус» `is not` «Выполнена».
4.  **Flow-узел**: `Iterate` — для каждой просроченной задачи:
    *   Действие `Send email` → отправить напоминание исполнителю.
5.  Включите Workflow.

## Часть 6: Настройка ролей и прав доступа

Чтобы каждый сотрудник видел только ту информацию, которая ему необходима, настройте роли. NocoDB поддерживает следующие роли [[6]](https://nocodb.com/docs/product-docs/roles-and-permissions):

| Роль | Права | Кому назначать |
|---|---|---|
| **Owner** | Полный доступ, включая настройки | Владелец бизнеса, IT-администратор |
| **Creator** | Создание и изменение таблиц, полей, представлений | Руководители отделов |
| **Editor** | Добавление и редактирование записей | Менеджеры по продажам, маркетологи |
| **Commenter** | Просмотр и добавление комментариев | Аналитики, наблюдатели |
| **Viewer** | Только просмотр | Внешние партнеры, топ-менеджмент |

**Инструкция по приглашению:**
1.  Нажмите на иконку `Share` в правом верхнем углу вашего Base.
2.  Введите email сотрудника и выберите соответствующую роль.
3.  Нажмите `Invite`.

## Часть 7: Полезные советы по оптимизации

Для того чтобы ваша CRM работала максимально эффективно, рекомендуется придерживаться следующих практик.

**Используйте поля Rollup и Lookup.** После создания связей между таблицами вы можете добавить поля типа `Rollup` для агрегации данных из связанных таблиц. Например, в таблице «Клиенты» можно добавить поле `Сумма всех сделок` (тип `Rollup`, операция `Sum` по полю «Сумма» из связанной таблицы «Сделки»). Это позволит сразу видеть ценность каждого клиента без перехода в другую таблицу.

**Настройте цветовую маркировку записей.** В любом Grid-представлении вы можете настроить цвет строк в зависимости от значения поля. Например, в таблице «Задачи» выделите красным строки, где «Приоритет» = «Высокий» и «Статус» = «К выполнению». Это мгновенно привлечет внимание к срочным задачам.

**Используйте группировку данных.** В Grid-представлении нажмите `Group by` и выберите поле для группировки. Например, в таблице «Сделки» сгруппируйте по «Ответственному», чтобы видеть нагрузку на каждого менеджера.

**Экспортируйте данные при необходимости.** NocoDB позволяет экспортировать любую таблицу или представление в формат CSV или Excel. Это полезно для создания отчетов в сторонних инструментах.
