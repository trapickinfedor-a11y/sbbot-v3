
# Newlookup — Тест-кейсы и сценарии ручного тестирования

## Сценарий 1: Полный цикл покупателя

| Шаг | Действие | Ожидаемый результат |
| :--- | :--- | :--- |
| 1 | Запустить Mirror Bot, отправить `/start` | Бот приветствует, предлагает выбрать язык. |
| 2 | Выбрать язык | Меню обновляется на выбранном языке. |
| 3 | Нажать "Профиль" | Отображается профиль: ID, баланс 0, нет заказов. |
| 4 | Нажать "Пополнить баланс", выбрать BTC, ввести 0.001 | Бот выдаёт BTC-адрес и сумму для оплаты. |
| 5 | (Симуляция) Отправить транзакцию | Через 1-3 минуты баланс пополняется. |
| 6 | Нажать "Каталог", выбрать категорию, выбрать товар | Отображается карточка товара с кнопкой "Купить". |
| 7 | Нажать "Купить" | Бот списывает деньги, присылает содержимое товара. |
| 8 | В закреплённом сообщении нажать "Оценить", поставить 5 звёзд | Бот благодарит за оценку. |

## Сценарий 2: Полный цикл продавца

| Шаг | Действие | Ожидаемый результат |
| :--- | :--- | :--- |
| 1 | Запустить Seller Bot, отправить `/start` | Бот просит внести депозит $600. |
| 2 | (Симуляция) Пополнить депозит | Бот предоставляет доступ к главному меню. |
| 3 | Нажать "Загрузить товар", выбрать категорию, пройти FSM | Товар успешно загружен, уходит на модерацию. |
| 4 | (Симуляция) Админ одобряет товар | Продавец получает уведомление. |
| 5 | (Симуляция) Покупатель покупает товар | Продавец получает уведомление о продаже, деньги на hold-балансе. |
| 6 | (Симуляция) Проходит 24 часа | Деньги переходят с hold на основной баланс. |
| 7 | Нажать "Вывод средств", ввести сумму и адрес | Заявка на вывод создана. |
| 8 | (Симуляция) Финансист одобряет вывод | Продавец получает уведомление, деньги отправлены. |
