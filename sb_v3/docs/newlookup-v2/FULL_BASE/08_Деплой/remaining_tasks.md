# Что осталось реализовать (финальные задачи)

Это финальный список задач для 100% завершения проекта.

---

| Агент | Задача | Детали |
| :--- | :--- | :--- |
| **1. Mirror Bot** | **Купоны, Чат, Конфигураторы** | - Реализовать флоу применения купонов.
- Реализовать прокси-чат Покупатель ↔ Продавец.
- Добавить конфигураторы для `Fullz` и `eSIM`. |
| **3. Seller Bot** | **Завершить флоу депозитов** | - **BTCPay Webhook:** Убедиться, что он не только вызывает `process_paid_invoice`, но и корректно обновляет статус платежа и **автоматически разблокирует категории** для продавца. |
| **4. Worker Bot** | **Завершить флоу воркера** | - Реализовать **авто-напоминания** каждые 2 часа о заказах в обработке.
- Реализовать полный функционал кнопок (`ГОТОВО`, `НН`, `Отменить`, `Пожаловаться`). |
| **5. Support Bot** | **Массовые рассылки** | - Реализовать функционал массовых рассылок по группам (воркеры, продавцы, маркетологи, все). |
| **6. Admin Panel** | **Ключевые настройки** | - Реализовать управление ценами/таймерами в `pricing_config`.
- Реализовать управление воркерами и их ставками. |
| **9. NocoDB Agent** | **Полное логирование** | - Внедрить `NocoDBService` во все 8 ключевых событий, описанных в ТЗ (сейчас логируются только покупки `seller_specials`). |
