## Часть 1: Суть проекта

**ONE Bot** — это многоагентная Telegram-экосистема, представляющая собой полноценный маркетплейс. Проект состоит из 9 взаимосвязанных агентов, каждый из которых выполняет свою функцию:

| Агент | Назначение |
| :--- | :--- |
| **1. Mirror Bot** | Основная витрина для покупателей. Динамический каталог товаров. |
| **2. Marketing Bot** | Партнерская программа для привлечения трафика. Маркетологи получают зеркала и % с продаж. |
| **3. Seller Bot** | Кабинет для продавцов. Загрузка товаров, управление стоком, финансы. |
| **4. Worker Bot** | Биржа услуг. Воркеры выполняют заказы, которые не могут быть автоматизированы. |
| **5. Support Bot** | Система модерации и поддержки. Обработка жалоб, модерация товаров. |
| **6. Admin Bot** | Панель управления для администраторов. Роли, выплаты, глобальные настройки. |
| **7. Uploader Agent** | Универсальный механизм загрузки и парсинга всех типов товаров. |
| **8. Buyer Agent** | Логика покупки, гарантий, споров и рейтингов. |
| **9. NocoDB Agent** | Сервис для логирования всех ключевых событий в NocoDB для аналитики. |

**Ключевая цель** — создать автоматизированную, масштабируемую и безопасную платформу для торговли цифровыми товарами и услугами внутри Telegram.

## 1. ИСПРАВЬ МИГРАЦИИ в `shared/database/session.py`

В файле `shared/database/session.py` есть список `POST_CREATE_MIGRATIONS`. Сейчас он выглядит так:

```python
POST_CREATE_MIGRATIONS = [
    # ... другие миграции
    (
        "ALTER TABLE seller_enroll_items ADD COLUMN guarantee_until TIMESTAMP",
        "ALTER TABLE seller_enroll_items ADD COLUMN IF NOT EXISTS guarantee_until TIMESTAMP",
    ),
    # ... и так далее
]
```

Это неправильно. Каждая миграция должна быть одной строкой. Приведи его к правильному виду:

```python
POST_CREATE_MIGRATIONS = [
    # ... другие миграции
    ("ALTER TABLE seller_enroll_items ADD COLUMN IF NOT EXISTS guarantee_until TIMESTAMP",),
    ("ALTER TABLE seller_selfreg_ba_items ADD COLUMN IF NOT EXISTS guarantee_until TIMESTAMP",),
    ("ALTER TABLE seller_logs_items ADD COLUMN IF NOT EXISTS guarantee_until TIMESTAMP",),
    ("ALTER TABLE seller_check_orders ADD COLUMN IF NOT EXISTS guarantee_until TIMESTAMP",),
    ("ALTER TABLE seller_nfc_orders ADD COLUMN IF NOT EXISTS guarantee_until TIMESTAMP",),
    ("ALTER TABLE seller_otp_orders ADD COLUMN IF NOT EXISTS guarantee_until TIMESTAMP",),
    ("ALTER TABLE seller_selfreg_cc_orders ADD COLUMN IF NOT EXISTS guarantee_until TIMESTAMP",),
]
```

Удали все старые, неправильные ALTER TABLE для `guarantee_until` и замени их этим списком. **Важно:** используй `IF NOT EXISTS` для всех.
