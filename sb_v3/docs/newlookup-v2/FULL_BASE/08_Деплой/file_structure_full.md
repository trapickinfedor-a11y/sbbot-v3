### Описание компонентов

*   **app/**: Сердце проекта. Весь код на Python находится здесь.
*   **app/bots/**: Каждый бот — это отдельный модуль со своей логикой, хендлерами и точкой входа. Это позволяет разрабатывать и перезапускать ботов независимо.
*   **app/core/**: Общие для всего приложения вещи: загрузка конфигурации из `.env`, утилиты для безопасности (JWT, пароли), функция локализации.
*   **app/db/**: Всё для работы с PostgreSQL. Модели (`models/`) описывают таблицы, `session.py` настраивает подключение, `base.py` — основа для моделей.
*   **app/services/**: Бизнес-логика, которая может быть использована в разных частях приложения (например, и в боте, и в API). Здесь же находятся Celery-задачи для фоновых процессов.
*   **app/web/**: Код для веб-сервисов на FastAPI. Разделено на `admin` (панель администратора) и `mini_app` (бэкенд для веб-приложения продавца).
*   **alembic/**: Инструмент для миграций схемы базы данных. Позволяет версионировать изменения в структуре таблиц.
*   **docs/**: Вся документация, необходимая для понимания и разработки проекта.
*   **frontend/**: Исходный код для клиентских веб-приложений. В данном случае — для Seller Mini App.
*   **locales/**: JSON-файлы с переводами всех строк интерфейса на поддерживаемые языки.
*   **scripts/**: Скрипты для выполнения разовых задач, например, для первоначального наполнения базы данных.
*   **.env.example**: Шаблон для файла `.env`, который содержит все необходимые переменные окружения. `.env` не должен храниться в Git.
*   **docker-compose.yml**: Оркестратор для запуска всех компонентов проекта (база данных, Redis, боты, API) в изолированных контейнерах.
*   **requirements.txt**: Список всех Python-библиотек, необходимых для работы проекта. Устанавливаются командой `pip install -r requirements.txt`.
