# Что планировалось по ТЗ v2.0

Этот документ — выжимка изначального ТЗ. Это то, что **должно было быть** реализовано.

---

| Агент | Ключевые требования по ТЗ v2.0 |
| :--- | :--- |
| **1. Mirror Bot** | - Система купонов
- Чат Покупатель ↔ Продавец
- Рейтинг заказов (Like/Dislike)
- PDF-мануалы с водяными знаками
- Конфигураторы для Fullz и eSIM
- **Счетчики товаров в кнопках**
- Новые категории в меню |
| **2. Marketing Bot** | - Отдельный бот для партнеров
- Дашборд со статистикой
- **Лимит 5 зеркал на маркетолога**
- **Уведомление владельцу при 50 регистрациях** |
| **3. Seller Bot** | - **Депозиты через BTCPay с авто-подтверждением**
- **4 пакета доступа к категориям**
- Веб-приложение для продавцов |
| **4. Worker Bot** | - Отдельный бот для воркеров
- Дашборд со статистикой
- Флоу обработки заказов с кнопками
- **Авто-напоминания каждые 2 часа** |
| **5. Support Bot** | - Роли: Модератор, Саппорт, Загрузчик, Бухгалтер, Админ
- **Массовые рассылки по группам** |
| **6. Admin Panel** | - 24 пункта меню в 7 группах
- **Управление ценами/таймерами**
- **Управление воркерами и их ставками**
- Управление категориями |
| **7. Upload Agent** | - **Парсеры для 9 категорий** (CC, NFC, Enroll, OTP, Selfreg BA, Selfreg CC, Logs, Brute, Checks)
- Авто-определение подкатегорий для CC |
| **8. Buyer Agent** | - Универсальный флоу покупки
- **Гарантийные окна для всех 9 категорий** |
| **9. NocoDB Agent** | - **Логирование 8 ключевых событий** (чаты, модерация, финансы, ошибки и т.д.) |
