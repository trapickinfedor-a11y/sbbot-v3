# Seller Mini App — Полный аудит UI

## Навигация (Нижнее меню)
- **Chats** (Чаты) — Список диалогов.
- **Orders** (Заказы) — Список заказов по статусам.
- **Upload** (Загрузка) — Центр загрузки данных по категориям.
- **Stats** (Статистика) — Аналитика продаж.
- **Finance** (Финансы) — Баланс и выплаты.
- **Team** (Команда) — Управление сотрудниками.
- **More** (Еще) — Настройки и доп. функции.

## Раздел: Chats (Чаты)
### Элементы UI
- **Хедер:** Аватар пользователя, имя "Alex Petrov", подзаголовок "Seller Hub", иконка колокольчика (уведомления) с индикатором "2".
- **Поиск:** Поле ввода "Search chats...".
- **Список чатов:** Карточки чатов с названием, превью последнего сообщения, временем и статусом.
- **Статус-баджи:** "In Progress", "Approved", "Disputed", "Completed".
- **Индикаторы сообщений:** Синие кружки с числом непрочитанных сообщений.

### Данные
- Список активных диалогов (Chase Business, Wells Fargo Personal, Bank of America VCC, Citibank Selfreg).
- Временные метки (3m ago, 45m ago, 2h ago, 1d ago).

### Действия
- Поиск по чатам, переход в диалог, просмотр уведомлений.

### Проблемы
- Не обнаружено.

## Раздел: Orders (Заказы)
### Элементы UI
- **Табы/Фильтры:** "Active", "All", "Done", "Disputed".
- **Пустое состояние:** Иконка коробки и надпись "No orders found".

### Данные
- Активных заказов в списке нет.

### Действия
- Переключение между табами (Active, All, Done, Disputed).

### Проблемы
- Несоответствие: на иконке в меню висит уведомление "2", но в табе "Active" пусто.

## Раздел: Upload (Загрузка)
### Элементы UI
- **Заголовок:** "Upload Center", "10 / 10 sections unlocked".
- **Кнопка:** "Packages".
- **Список категорий:** 10 категорий (Banks, Brute Bank, CC, NFC, OTP, Selfreg CC, Enrollment, Logs, Checks, Selfreg BA) с иконками, тегами и стрелками перехода.

### Данные
- Доступные категории загрузки и их описания.

### Действия
- Переход в детальную форму загрузки каждой категории, просмотр пакетов.

### Проблемы
- Не обнаружено.

## Раздел: Stats (Статистика)
### Элементы UI
- **Селектор месяца:** Стрелки, текущий месяц "March 2026".
- **Таймлайн:** Горизонтальный список месяцев.
- **Переключатели периода:** "7D", "30D", "3M", "Month".
- **Кнопки:** "Refresh", "Export CSV".

### Данные
- Графики и цифры отсутствуют в текущем состоянии (возможно, из-за демо-режима или отсутствия данных).

### Действия
- Смена периода, переключение месяцев, обновление, экспорт.

### Проблемы
- Интерфейс пустой, хотя выбран текущий месяц.

## Раздел: Finance (Финансы)
### Элементы UI
- **Форма вывода:** "WITHDRAW FUNDS" с полями Amount и Requisites (BTC/XMR ONLY!!).
- **Кнопка:** "Request Withdrawal".
- **Карточка экспорта:** "Export CSV" для истории транзакций.

### Данные
- Реквизиты и суммы (пустые поля). Текущий баланс не отображается.

### Действия
- Заполнение формы вывода, запрос выплаты, экспорт истории.

### Проблемы
- Отсутствие баланса в явном виде.

## Раздел: More (Еще)
### Элементы UI
- **Инфо-плашка:** "Demo mode — connect to your backend to see live data".
- **Профиль:** Аватар, имя, статус "Active", депозит "paid".
- **Настройки:** Vacation Mode, Auto-Payout, Quiet Hours, Interface Language (EN/RU).

### Данные
- Конфигурация профиля и настройки уведомлений/режима работы.

### Действия
- Переключение режимов, сохранение настроек тихих часов, смена языка.

### Проблемы
- Режим Demo mode ограничивает видимость реальных данных.

## Общие наблюдения
1. Приложение адаптировано под мобильный формат (миниапп).
2. UX логичен, все основные функции селлера вынесены в нижнее меню.
3. Визуальный стиль выдержан в темных тонах с яркими акцентами на статусах и кнопках.
4. Основное замечание: отсутствие баланса в разделе Finance и пустые графики в Stats.
