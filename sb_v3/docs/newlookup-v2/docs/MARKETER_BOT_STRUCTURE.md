# 📢 Структура Marketer Bot

## Обзор

Полная система для маркетологов: аналитика с графиками, выводы по запросу, логи всех действий, возможность работать с несколькими ботами.

---

## 🗄️ База данных

### Новые таблицы

| Таблица | Назначение |
|--------|------------|
| `marketer_activity_logs` | Лог всех действий: начисления, заявки на вывод, одобрения, отклонения |
| `marketer_bot_links` | Связь маркетолога с ботами (для аналитики по ботам) |

### MarketerActivityLog

- `action`: earning, withdrawal_request, withdrawal_approved, withdrawal_rejected
- `amount`, `details`, `withdrawal_id`, `mirror_bot_id`, `user_id`, `processed_by`

## 🤖 Marketer Bot (Telegram)

### Команды

| Команда | Описание |
|---------|----------|
| `/start` | Дашборд с балансом, статистикой, кнопками |
| `/promo` | Промокод и реферальные ссылки для каждого бота |
| `/logs` | Последние 15 записей лога действий |
| `/withdraw` | Заявка на вывод средств |
| `/help` | Справка по командам |
| `/broadcast` | (Только админ) Рассылка всем пользователям |

### Кнопки дашборда

- 🔗 Промокод и ссылки
- 💸 Вывод
- 📋 Лог действий
- 🔄 Обновить

### Реферальные ссылки

Формат: `https://t.me/{bot}?start=promo_{PROMOCODE}`

При переходе по ссылке промокод применяется автоматически.

## 🌐 Web Panel (Админка)

### Страница /marketers

**Вкладки:**

1. **Обзор** — заявки на вывод (ожидают), список маркетологов
2. **Выводы** — полная история с фильтром по статусу
3. **Аналитика** — графики по выбранному маркетологу:
   - Заработок по дням (линейный график)
   - Регистрации и первые пополнения (столбчатая диаграмма)
   - Статистика по ботам (рефералы, баланс юзеров)
4. **Логи** — лог действий выбранного маркетолога

### API

| Endpoint | Описание |
|----------|----------|
| `GET /api/marketers` | Список маркетологов |
| `GET /api/marketers/withdrawals` | Заявки на вывод |
| `GET /api/marketers/withdrawals/full` | Полная история выводов |
| `GET /api/marketers/{id}/analytics?days=30` | Данные для графиков |
| `GET /api/marketers/{id}/stats-by-bot` | Статистика по ботам |
| `GET /api/marketers/{id}/activity-log` | Лог действий |
| `POST /api/marketers/withdrawals/{id}/approve` | Одобрить вывод |
| `POST /api/marketers/withdrawals/{id}/reject` | Отклонить вывод |

---

## 📋 Логирование

Автоматически записываются:

- **earning** — начисление комиссии с пополнения реферала
- **withdrawal_request** — маркетолог создал заявку на вывод
- **withdrawal_approved** — админ одобрил вывод
- **withdrawal_rejected** — админ отклонил вывод

---

## 🔧 Запуск

Marketer Bot запускается через Docker (marketer_bot) или отдельно:

```bash
MARKETER_BOT_TOKEN=... ADMIN_IDS=... python -m marketer_bot.bot
```

В `.env` должны быть: `MARKETER_BOT_TOKEN`, `ADMIN_IDS`, `DATABASE_URL`.
