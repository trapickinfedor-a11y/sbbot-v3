# 🤖 Система владельцев ботов

## Обзор

Владелец может создать несколько ботов, видит статистику по всем ботам (суммарно), получает 7% с пополнений (отображается 10%), выводит средства (мин. $100). Админ получает уведомление о заявке и нажимает «Выплатил» — баланс обнуляется, статистика сохраняется.

---

## База данных

| Таблица | Назначение |
|--------|------------|
| `bot_owners` | Баланс владельца: owner_user_id, balance, total_earned, total_withdrawn |
| `bot_owner_stats` | Ежедневная статистика по боту: mirror_bot_id, date, spent, topped_up, owner_income |
| `bot_owner_withdrawals` | Заявки на вывод |

---

## Комиссия

- **Реально начисляется:** 7% с каждого пополнения пользователей
- **Отображается владельцу:** 10%
- Владелец не получает % с своего собственного пополнения

---

## Main Bot — личный кабинет

### Кнопка «Личный кабинет»

- **Без ботов:** приглашение создать бота, ссылка на видео/инструкции
- **С ботами:** баланс, доход за день/неделю/месяц, потрачено, пополнено

### Возможности

- **Создать бота** — отправить токен от @BotFather (можно несколько ботов)
- **Моя статистика** — детальная разбивка
- **Вывод средств** — мин. $100, ввод реквизитов
- **Создать ещё бота** — добавить следующий бот

### Статистика (суммарно по всем ботам)

- Потратили (заказы)
- Пополнили (топ-апы юзеров)
- Ваш доход за день / неделю / месяц / всего

---

## Вывод средств

1. Владелец нажимает «Вывод» в личном кабинете
2. Вводит сумму (мин. $100) и реквизиты
3. Админ получает уведомление в Telegram
4. Админ заходит в веб-панель → Маркетологи → вкладка «Выводы владельцев ботов»
5. Нажимает «Выплатил» — баланс владельца обнуляется, total_withdrawn обновляется
6. Вся статистика (spent, topped_up, income) сохраняется

---

## Ежедневный отчёт

Каждый день в 9:00 UTC владельцам с активными ботами отправляется уведомление со статистикой:

- Баланс
- Доход всего
- За день / неделю / месяц: потратили, пополнили, ваш доход

## API

| Endpoint | Описание |
|----------|----------|
| `GET /api/bot-owners/withdrawals` | Список заявок на вывод |
| `POST /api/bot-owners/withdrawals/{id}/pay` | Подтвердить выплату |
| `POST /api/bot-owners/withdrawals/{id}/reject` | Отклонить |

---

## Настройки

- `ADMIN_IDS` — кому приходят уведомления о заявках на вывод
- `MAIN_BOT_TOKEN` — для отправки ежедневных отчётов и уведомлений
