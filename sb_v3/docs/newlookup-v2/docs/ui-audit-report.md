## 🟡 ЧТО ЛИШНЕЕ / ПОДОЗРИТЕЛЬНОЕ

| # | Где | Элемент | Почему лишнее |
|---|-----|---------|---------------|
| 1 | Mini App → More | Плашка "Demo mode — connect to your backend" | Не должна быть в продакшн-сборке. Либо убрать, либо привязать к `.env` флагу |
| 2 | Mini App → Finance | "BTC/XMR ONLY!!" | Хардкод метода вывода в UI — должно быть в конфиге, не в интерфейсе |
| 3 | Admin → Dashboard | 6 подразделов (Обзор, Finance Hub, Аналитика, Отчёты, Ops Dashboard, Автоматизация) | Слишком много для одного дашборда. Finance Hub дублирует Finance в других местах. Ops Dashboard и Автоматизация — скорее всего заглушки |
| 4 | Admin → Catalog | Подразделы "Банки", "Brute Bank", "Аккаунты" | Дублируют категории из Upload в миниаппе. Нужна единая точка управления |
| 5 | Admin → Users → Рассылки | Непроверенный функционал массовых рассылок | Опасный инструмент без видимых ограничений (rate limits, подтверждения) |
| 6 | Admin → Settings → "Импорт из кода" | Цены пустые, требуется ручной импорт | Начальные цены должны инициализироваться автоматически |
