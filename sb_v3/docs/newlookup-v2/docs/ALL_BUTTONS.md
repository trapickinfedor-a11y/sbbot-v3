## 30. eSIM — SMS / DATA / GOOGLE VOICE (каталог из БД)

Список кнопок **динамический**: по одной строке на каждый активный `AccountItem`:
- SMS: `category_code = esim_sms`
- Data: `category_code = esim_data`
- Google Voice: `category_code = gv`

Формат текста кнопки: `{name} — ${price}`  
Callback: `esim_item:{id}`

```
{позиция 1} — $…
{позиция 2} — $…
…
⬅️ Back   → esim_back_main
```

---

## 31. eSIM — КАРТОЧКА ТОВАРА + КОЛИЧЕСТВО (SMS / Data / GV)

После `esim_item:{id}` — описание, затем:

```
2️⃣    | 3️⃣ (-5%)   | 5️⃣ (-10%)
🔟 (-15%)
✅ Buy 1 item
⬅️ Back   → esim_iback:{id}
```

Callbacks: `esim_iq:{id}:{qty}`, `esim_ib:{id}:1`  
Опт: подтверждение `confirm_bulk_esim` / `cancel_bulk_esim` (FSM `ESIMStates.confirm_bulk_purchase`).
