🔄 Key User Flows
👤 New User Onboarding
1
/start [ref_code?]
Parses referral link. Creates user record. Sets referrer_id if ref present.
2
Language Select
Auto-detect from Telegram language_code. EN / RU / ZH / ES.
3
Rules Gate
User must accept terms. Blocked until accepted.
4
Onboarding Tour (optional)
Guided tour of main features. Can be skipped.
5
Welcome Coupon (WELCOME10)
Auto-issued to all new users.
6
Main Menu
Reply keyboard with dynamic categories from DB.
💰 Purchase Flow
1
Category → Item Selection
User browses catalog. Inline keyboard with counts from cache.
2
Configurator (if applicable)
FULLZ / eSIM / Banks: multi-step price builder.
3
Quantity + Bulk Discount
Select qty. DB-loaded tiers applied automatically.
4
Coupon Code (optional)
Apply coupon at checkout. Validates + calculates discount.
5
Balance Deduct → Order Created
Ledger debit. Order record created. Referral chain credited.
6
Delivery
Instant (product catalog) or Worker-fulfilled (banks, FULLZ, docs).
💳 Top-Up Flow
1
Choose Payment Method
CryptoPay (3% fee) or Cryptomus (2% fee).
2
Invoice Created
Payment link generated via external API. Shown with QR.
3
Polling / Webhook
PaymentMonitor polls status. Updates on paid/expired.
4
Balance Credited
Ledger credit. 3% first-deposit bonus if applicable. Bot owner +7%.

🏪 Seller Fulfillment Flow
1
Seller uploads inventory
Via seller_bot upload wizard or bulk CSV import.
2
Moderation (admin review)
Products approved/rejected in support_bot or web panel.
3
Customer purchases
SellerOrder created. Funds held in escrow.
4
Seller delivers
Seller marks complete via seller_bot. Dispute window opens.
5
Auto-confirm (3 days)
If no dispute, escrow released to seller automatically.
🤖 Mirror Bot Lifecycle
1
Owner submits token to main_bot
Token validated via Bot.get_me(). Saved to mirror_bots table.
2
create_mirror_bot(token)
New Bot + Dispatcher. All 31 routers + 7 middlewares attached.
3
asyncio.create_task(_run_polling)
Runs independently. Auto-retries on crash (exp. backoff, max 120s).
4
restore_all_bots() on restart
All active tokens re-launched automatically on main_bot start.
